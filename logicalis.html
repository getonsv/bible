Technical FAQ — Short Answers

Canvas vs Model-Driven

Canvas: best for pixel-perfect UI and mixed data sources. Model-Driven: use when Dataverse relational model & business rules are core. Consider maintenance and licensing trade-offs.

Delegation & Performance

Use delegable functions (Filter, Lookup), pre-filter server-side, cache via collections, minimise controls & nested galleries. Use App Checker & Monitor. If necessary, move heavy queries to SQL/Dataverse views.

Power Automate & RPA best practices

Modular flows, naming conventions, scopes + run-after for error handling, logging, retry policies. For extensive automation consider combining Power Automate with RPA (UiPath) where UI automation is required.

Integration (Custom connectors / Azure)

Use OpenAPI to create custom connectors, handle auth (OAuth2), perform transformations via Azure Functions or Logic Apps, keep secrets in Key Vault or environment variables.

ALM & Governance

Environments: Dev/Test/Prod. Use solutions (managed for Prod), Git + Azure DevOps for source control, and pipelines with Power Platform build tools. Use CoE Starter Kit to monitor usage & governance.
