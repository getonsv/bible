Technical FAQ (short answers)

Practice answers
Canvas vs Model-Driven — quick answer
Canvas: best for bespoke UI & multi-source apps. Model-Driven: when data model is primary — many relationships, business rules and enterprise scale. Mention licensing trade-off and maintenance. (Use example: Inventory app on resume). [oai_citation:6‡4210_Resume_Steven.pdf](sediment://file_000000005c6872078749d36945ff0ba8)
Handling delegation and performance
Use delegable functions, pre-filter in server, replace non-delegable queries with Dataverse or SQL, use collections to cache, reduce controls and nested galleries, use App Checker & Monitor.
Power Automate best practices
Modular flows, meaningful names, scopes with run-after for error handling, retry policies, centralised logging (SharePoint / Log table / Azure Monitor), test in sandbox. Mention you built 95+ flows in past role. [oai_citation:7‡4210_Resume_Steven.pdf](sediment://file_000000005c6872078749d36945ff0ba8)
Third-party integration
Build custom connector (OpenAPI/Swagger), auth via OAuth or API key, transform payload using Azure Functions or Logic Apps if complex, store secrets in Key Vault or environment variables.
ALM / Governance
Dev / Test / Prod environments, use managed solutions for Prod, version control in Git/Azure DevOps, pipelines with Power Platform Build Tools, CoE Starter Kit for monitoring & best practices.
